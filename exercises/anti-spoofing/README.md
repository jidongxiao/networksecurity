# Exercise: IP Spoofing and Anti-Spoofing with `iptables`

In this exercise, you will use three Linux VMs to demonstrate **IP source-address spoofing** and how a firewall can prevent spoofed packets using `iptables`.

## 1. Network Topology

We will use three VMs: VM2 acts as the **router and firewall** between VM3 and VM1.

| VM  | Interface | IP Address    | Network       |
| --- | --------- | ------------- | ------------- |
| VM1 | `enp0s3`    | `10.0.2.4/24` | `10.0.2.0/24` |
| VM2 | `enp0s3`    | `10.0.2.5/24` | `10.0.2.0/24` |
| VM3 | `enp0s3`    | `10.0.2.6/24` | `10.0.2.0/24` |

VM3 uses VM2 as its default gateway:

```text
VM3 default gateway: 10.0.2.5
```

---

## 2. Configure the Network

### VM2

Enable IPv4 forwarding:

```bash
sudo sysctl -w net.ipv4.ip_forward=1
```

Verify:

```bash
sysctl net.ipv4.ip_forward
```

It should show:

```text
net.ipv4.ip_forward = 1
```

### VM3

Use VM2 as its default gateway:

```bash
sudo ip route add default via 10.0.2.5
```

Verify:

```bash
ip route
```

---

## 3. Test Normal Connectivity

From VM3, ping VM1:

```bash
ping 10.0.2.4
```

The packets should travel through VM2:

```text
VM3 → VM2 → VM1
```

On VM2, use `tcpdump` to observe the traffic:

```bash
sudo tcpdump -n -i enp0s3 icmp
```

You should be able to observe the ICMP packet entering VM2 through `enp0s3` and leaving through `enp0s3`.

---

## 4. Generate a Packet with Scapy

Scapy allows us to construct packets with arbitrary IP headers.

On VM3, start Python:

```bash
sudo python3
```

Then:

```python
from scapy.all import *

send(IP(src="10.0.2.6", dst="10.0.2.4")/ICMP())
```

The packet claims to originate from VM3:

```text
Source:      10.0.2.6
Destination: 10.0.2.4
```

Because `10.0.2.6` is VM3's legitimate address, VM2 should forward the packet.

---

## 5. Spoof the Source Address

Now change the source address:

```python
send(IP(src="1.2.3.4", dst="10.0.2.4")/ICMP())
```

The packet is actually generated by VM3, but it claims to come from VM2:

```text
Actual sender: VM3
Source address: 1.2.3.4
Destination:    10.0.2.4
```

Without anti-spoofing protection, VM2 may forward this packet even though the source address is not legitimate for the interface on which the packet arrived.

---

## 6. Add an Anti-Spoofing Rule

VM2 expects packets arriving from the `10.0.2.0/24` network to have
a source address belonging to that network.

First, add a logging rule:

```bash
sudo iptables -A FORWARD -i enp0s3 ! -s 10.0.2.0/24 \
    -j LOG --log-prefix "ANTI-SPOOF: "
```

Then add the corresponding drop rule:

```bash
sudo iptables -A FORWARD -i enp0s3 ! -s 10.0.2.0/24 \
    -j DROP
```

The two rules work together:

```text
Packet arrives on enp0s3
          |
          v
Source in 10.0.2.0/24?
       /       \
     yes        no
      |          |
   forward    log packet
                 |
                 v
               DROP
```

The first rule records packets that violate the expected source network.
The second rule prevents those packets from being forwarded.

Check the rules:

```bash
sudo iptables -L FORWARD -n -v
```

You should see both the `LOG` and `DROP` rules.

To observe the log messages in real time, run the following on VM2:

```bash
sudo journalctl -k -f | grep ANTI-SPOOF
```

---

## 7. Test the Anti-Spoofing Rule

### Legitimate packet

From VM3, send a packet with a valid source address:

```python
send(IP(src="10.0.2.6", dst="10.0.2.4")/ICMP())
```

This packet should be forwarded by VM2.

### Spoofed packet

Now send a packet with a forged source address outside the
`10.0.2.0/24` network:

```python
send(IP(src="1.2.3.4", dst="10.0.2.4")/ICMP())
```

This packet should be:

1. **Logged** by the `LOG` rule.
2. **Dropped** by the `DROP` rule.
3. **Not forwarded** to VM1.

Look at the terminal running:

```bash
sudo journalctl -k -f | grep ANTI-SPOOF
```

You should see a log entry containing the spoofed packet's source and
destination addresses.

You can also check the packet counters:

```bash
sudo iptables -L FORWARD -n -v
```

The counters for the `LOG` and `DROP` rules should increase when the
spoofed packet is sent.
